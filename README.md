# Мир: страна за страной

Отчёты о заграничных поездках, страна за страной (название рабочее). Сайт: https://ssveretennikov.github.io/world/

- `index.html` — общий пост: страны по частям света (Европа, Азия, Африка, Америка).
- `<iso>-<год>-<тема>/` — страница поездки (`by-2025-grodno`), её фото и обложки роликов (`media/`).
- Ролики лежат рядом с фото в `<slug>/media/`: сайт с видео укладывается в 1 ГБ GitHub Pages, отдельный репозиторий не нужен (решение автора 06.10.2026).
- `src/` — тексты поездок, из которых собираются страницы.
- `trips/` — рабочие материалы (досье, отбор кадров, таблицы архива): закрытый репозиторий `ssveretennikov/world-trips`, локально папка внутри проекта со своим git; в сайт не входит.
- `journeys/` — страница «Поездки», `about/` — «О проекте» (собираются).
- `build.py` — сборка: `python build.py`.
- `tools/media.py` — подготовка фото и видео из архива.
- `series.css`, `series.js`, `map.js` — общее оформление и скрипты (из «России»).
- `fonts/` — шрифты Unbounded, Golos Text и Oswald (WOFF2, лицензии OFL), подключаются в начале `series.css`.

## Карта на главной

`data/map.json` — контуры стран (делает `python tools/map.py путь/к/ne_110m_admin_0_countries.geojson`, данные Natural Earth, нужен numpy). Пока файла нет, главная собирается без карты. Дата первого визита в страну берётся из `data/trips.json`.
